# Santa — santafeat.com

Web del sello creativo Santa (Eva Santos). Sitio estático publicado en Netlify desde este repositorio: cada cambio en `main` se publica automáticamente.

- `index.html` — página completa.
- `img/` — imágenes de reposo de cada pieza, logos y foto.
- `clips/` — clips cortos sin sonido que se reproducen al pasar el ratón.
- `full/` — vídeos completos que se abren en el reproductor de la página al hacer clic.

Pendiente: versiones a 1080p de Gillette, Bijoux y Jägermeister; tipografía Hoefler Text (ahora Crimson Pro); enlace a Instagram.
